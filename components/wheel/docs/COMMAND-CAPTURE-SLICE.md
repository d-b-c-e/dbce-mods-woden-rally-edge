# Canonical command capture: bounded software slice

Based on canonical `7e806bb986e11166deca4bb03ead326837ba835d`. This implements a deliberately smaller schema than COMMAND-REPLAY-PROVENANCE-PROPOSAL.json. It does not adopt the excluded cadence candidate `11f780a55c15c91aa7403c80de3352f68446fbfb` or change shared toolkit source, binary pins, HAT39, native ABI, force model, gains, caps or settings defaults.

Production constructs `ForceController(device)` with no recorder. Only explicit internal constructor injection enables capture; there is no live capture UI, request, CLI or automatic file creation. Each recorder serves one controller runtime. A successful terminal shutdown is required before Finish. Restart after terminal shutdown marks this slice incomplete. No recorder I/O occurs in callbacks; explicit WriteNew exports after Finish with CreateNew, preserving existing files.

The default buffer holds at most 1,024 events (testable minimum 16), 64 session device tokens and a 1 MiB JSON file. Overflow, failed/invalid/backwards observation clocks, sink failure, calls after Finish or missing terminal shutdown make the footer incomplete. Actual device exceptions propagate through the existing cleanup path; their trace representation is State=1 with no raw message. Capture does not add native calls, read Error twice, change device arguments or recover failed calls. An injected observer is test infrastructure, not a guarantee against arbitrary reentrant observer code or resource exhaustion.

Events record exact consumed options bits plus SHA-256; model reset counts, preview bits and validity; preparation guards actually evaluated in existing short-circuit order; bounded target selection reasons, target changes and session tokens; IsReading; CanOpen/Open/CloseReaders/Refresh and device call begin/end with boolean outcomes; recovery zero writes; attempted output bits even when rejected; explicit resets; invocations and terminal-stop publication/shutdown completion. Gate observations occur before suppression/output and again at final legacy sample recording, where write-failed can replace active. Non-evaluated preparation guards are absent, not false. Successful target selection records `none` as its reason code; device names are never retained.

ClockBits is exact binary64 **injected callback observation time**, not native dispatch time or a cadence clock. Model events separately retain SimulationBits and SourceElapsedBits, which are the actual sample's model/source timestamps. They are not interchangeable. ControllerBase identifies the reviewed starting source, while ProducerAssemblySha256 hashes the actual loaded controller assembly; in the fixture it therefore identifies the test assembly, not the shipped plugin. This slice does not attest a source commit or effective config/profile file.

Complete means complete within this bounded software-call scope only. The fixed Unrecorded list explicitly excludes full model channel recomputation, cadence clock/epochs, native quantization/entry timing, driver/watchdog interventions, config/profile source attestation and concurrent actor correlation. Additional proposal omissions include settings revisions, complete pre/post controller snapshots, explicit notEvaluated rows, reason-specific error codes and raw channel sample identities. No claim of deterministic Unity input replay, full algorithm replay, delivered force, physical Nm, collision implementation, rig acceptance or visual triple-screen validation follows from a complete footer.

CommandCaptureAudit checks strict JSON field shapes, header/scope, footer/count/sequence consistency, clocks, exact options identity, bounded tokens/tags/errors and call transitions. Writes require a successfully opened token, exact finite normalized float bits and an ordered begin/end pair. Terminal success requires no pending call and no connected device. ReplayCalls validates first and projects only call-end observations into an explicitly supplied pure fake sink. It does not dispatch devices, recompute the model, execute invocations or validate the full proposal. Unknown JSON fields, duplicate properties, truncation and incomplete traces are refused.

The executable regression harness compiles the actual ForceController with the new observer and fake devices. It compares enabled/disabled call sequences and exact float bits, reader counts and setting saves; records recovery, target changes, panel suppression and failed output; exports/reads/validates a synthetic trace and projects its command sequence; refuses malformed/truncated/incomplete/invalid-transition/privacy/tampered inputs; verifies overflow, clock and sink faults leave controller behavior unchanged; and verifies an Open exception preserves original propagation and cleanup. Required Verify-Source also covers UI, offline triple geometry, probe compilation and normalized force-envelope fixtures. Generated synthetic captures remain ignored local evidence, outside Git and packages.

The next milestone is independent review of this isolated source candidate and its bounded schema. A broader producer would need separately reviewed plumbing for every omitted provenance field, lifecycle/concurrency correlation and safe live activation before an attended capture. Existing installed builds, settings, releases and frozen archives remain unchanged.
